# EZ2ON-Local-Viewer
Unofficial local score viewer for EZ2ON REBOOT:R

本アプリケーションは非公式で製作された、EZ2ON REBOOT:R用のローカルスコアビューワです。
原則としてゲーム本体やセーブデータの書き込み・改変・改竄を行わず、またアプリケーション単体の通信も行いません。
・日本語/英語/韓国語 のローカライズを収録
・譜面毎のスコア一覧、難易度表、RATINGの詳細表示、統計情報等を表示できます
・自己記録を細かくフィルタリングして分析することができます

ダウンロードはReleases欄から。必ずzipを展開した上、exeから起動してください。
記録を取得するには、ゲームを起動し、任意の選曲画面に入ってからアプリ内の「記録をリフレッシュ」を押してください。

本アプリケーションは現行最新アップデート版までに対応していますが、PUBLIC TESTクライアントを使用している場合は非対応です。
